1. 综述

布兰登・艾奇，这是个传奇人物，他有什么贡献呢？他用10天时间，把JavaScript带到了这 个世界上，其语言之精妙，以至于到今天，JavaScript还在被用作网页编程的语言。我们可 以看到，这个语言有很多设计十分具有“个性”，它有各种编程范式的各种特性，令人震惊 得是其究竟如何在语法上把这些特性融合到一起的。

今天我就给出一些我欣赏的一些设计，希望可以给读者一些启发。

2. C系语法

如果读到这里的读者学过C，同时也学过一点JavaScript，你就会发现这两个有多相似： 

for (int i = 0; i < 10; i++)
  {
    printf("%d", i);
  }

const printf = console.log; // 至少这样看起来是那么回事。

for (var i = 0; i < 10; i++)
{
    printf(i);
}

几乎很多语法是符合C程序的直觉的，大花括号，分号结尾等等，这些语法特性给了 JavaScript灵活的代码布局能力，编写者可以随意的折行。

3. 基于原型链的面向对象

这是JavaScript设计的一个亮点，即通过原型链构建的继承体系。

所谓原型链，就是对象的原型指向一个对象，并以此延伸的链条，如果一个源对象是对象的 原型，那么在调用对象的属性的时候，其会同时在此对象没有搜索到条目的时候在源对象中 搜索。

这个设计模式一开始是self语言提出的，后来JavaScript吸收了这部分设计模式，并使用这 个设计模式构建出自己的面向对象编程模式。

一个比较经典的例子就是继承的实现： 

function Person(age)
{
    this.age = age;
}

Person.exchangeAge = function(person1, person2)
{
    const temp = person2.age;
    person2.age = person1.age;
    person1.age = temp;
}

Person.prototype.getAge = function ()
{
    return this.age;
}

Person.prototype.setAge = function (newAge)
{
    this.age = newAge;
}

function prototypeInherit(SubType, SuperType)
{
    const prototype = Object.create(SuperType.prototype);
    prototype.constructor = SubType;
    SubType.prototype = prototype;
}

function PersonWithName(age, name)
{
    Person.call(this, age);
    this.name = name;
}

PersonWithName.exchangeName = function(person1,person2)
{
    const temp = person2.name;
    person2.name = person1.name;
    person1.name = temp;
}

prototypeInherit(PersonWithName,Person);

PersonWithName.prototype.getName = function()
{
    return this.name;
}

PersonWithName.prototype.setName = function(newName)
{
    this.name = newName;
}

代码中 Type.call(this, args ...) 和 prototypeInherit 函数就是实现继承的关键。 其中 Type.call 把父类的所有属性都继承下来，而 prototypeInherit 是把所有的实 例方法继承下来。而至于类方法，由于JavaScript是一个弱类型的语言，直接调用 Person 类中的类函数即可。

这个继承方式实际上就是现代JavaScript标准，即ES6中要求的 class 关键字的实现。

当然，使用原型链也可以用其他方式满足“继承”： 

function prototypeInherit(son, father)
{
    son.__proto__ = father;
}

const father = {a: 3, b: 4};
const son = {c: 5, d: 6};
prototypeInherit(son, father);
son.a; // => 3

这个也可以称为“继承”，因为其把属性继承下来了，如果把一部分属性改成函数，那就是 继承方法了，就是没有实现封装，所有的属性暴露在外面。具体这个到底是不是“正规的继 承”，得看你怎么定义了。还有一个值得一提的事情是：现代浏览器的js实现默认js中的原 型链是不会发生更改的，因此其采用了激进的优化手段，但是使用 __proto__ 属性会使 其回退至速度较低的原型链实现，导致性能大幅下降，因此请不要随意使用 __proto__ 属性。

4. 函数式编程支持

JavaScript支持把函数作为一个值进行赋值、传递等等操作： 

const handler = function (event) {
    console.log("hello");
}

document.addEventListener("DOMContentLoaded", handler);

function handler(event) {
    console.log("hello");
}

document.addEventListener("DOMContentLoaded", handler);

上面的两个用法效果相同，都是给DOM对象挂载一个函数，一旦DOM解析完成就执行这个函数。

有了这个能力，一些函数式搭配更改值的小技巧也可以实现一个“函数式的状态”。 

function makeState(val) {
    let state = val;
    function changeState(newVal) {
        state = newVal;
    }
    function getState() {
        return state;
    }
    return [getState, changeState];
}

这里，我们把一个值打包进一个“状态”，这个值会存储在这个函数的 state 变量中。

乍一看，可能觉得疑惑：我既然可以直接使用变量来存储值，我到底为什么需要把这个变量 放在一个闭包里边，用特定的函数来访问与更改？这就牵扯到了一个好玩的点了，我们可以 依据这个实现一个“钩子函数”，一旦状态更新，我们就按照注册的钩子来更新值。 

function makeState(val) {
    let state = val;
    const hooks = new Set();

    function addToHook(fn) {
        function removeFromHook() {
            hooks.delete(fn);
        }

        hooks.add(fn);
        return removeFromHook;
    }
    function updateHooks(next, prev) {
        function handleFn(fn) {
            fn(next, prev);
        }

        new Set(hooks)
            .forEach(handleFn)
    }
    function changeState(newVal) {
        const next =
              typeof newVal === 'function' ?
              newVal(state) :
              newVal;

        if (Object.is(next, state)) return;

        const prev = state;
        state = next;

        updateHooks(next, prev);
    }
    function getState() {
        return state;
    }
    return [getState, changeState, addToHook];
}

以上就是我们通过JavaScript的闭包特性以及值构建的状态函数。这个函数会返回一个具有 三个函数的数组，通过解构我们可以分别获得这三个函数： 

let [ getState, changeState, addToHook ] = makeState(1);

有了这个三个函数，基本上就可以控制这个状态了，比如我想构建一个计数器： 

let [ getState, changeState, addToHook ] = makeState(1);

let btn = document.getElementById("btn");
let cnt = document.getElementById("cnt");

function updateCnt() {
    cnt.innerText = getState().toString();
}

addToHook(updateCnt);
updateCnt();

function handleClick() {
    changeState((curr) => curr + 1);
}

btn.addEventListener('click', handleClick)

上面的代码构建了一个状态，然后把更新计数器的函数作为钩子，一旦运行 changeState 同时状态发生变化，就运行一次更新计数器的函数，之后把修改状态的函数挂载到按钮上， 这样就可以构建一个计数器。
